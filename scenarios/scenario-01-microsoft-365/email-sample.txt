============================================================
SUSPICIOUS INDICATORS IDENTIFIED
============================================================

1. SENDER SPOOFING / BRAND IMPERSONATION

Claimed identity:
Microsoft 365 Team

Actual sender domain:
micros0ft-verify.com

Observation:
The domain uses "micros0ft" instead of "microsoft".
The letter "o" has been replaced with the number "0".

Assessment:
Likely Microsoft brand impersonation / typosquatting.

------------------------------------------------------------

2. SPF AUTHENTICATION FAILURE

Result:
SPF = FAIL

Sending IP:
103.224.182.251

Observation:
The sending IP is not authorized to send email for
micros0ft-verify.com.

Assessment:
Strong indicator that the sender infrastructure is not
authorized by the domain's SPF policy.

------------------------------------------------------------

3. DKIM ABSENT

Result:
DKIM = NONE

Observation:
The message does not contain a valid DKIM signature.

Assessment:
The absence of DKIM alone does not prove phishing, but it
adds to the overall evidence when combined with SPF and
DMARC failure.

------------------------------------------------------------

4. DMARC AUTHENTICATION FAILURE

Result:
DMARC = FAIL

Policy:
p=REJECT

Observation:
The message failed DMARC authentication.

Assessment:
This is another strong indicator that the email should not
be trusted as an authenticated message from the claimed domain.

------------------------------------------------------------

5. REPLY-TO MISMATCH

From:
no-reply@micros0ft-verify.com

Reply-To:
account-verify@webmail-support.net

Observation:
The Reply-To address belongs to a completely different domain.

Assessment:
This is suspicious because the recipient could be redirected
to an unrelated mailbox if they respond.

------------------------------------------------------------

6. URGENCY / SOCIAL ENGINEERING

Subject:
Action Required: Your Microsoft 365 password expires in 24 hours

Message pressure:
- Password expires in 24 hours
- Verify credentials immediately
- Account suspension threat

Assessment:
The attacker is creating urgency and fear to encourage the
recipient to act without verifying the request.

------------------------------------------------------------

7. SUSPICIOUS URL

URL:
https://micros0ft-verify.com/o365/verify

Observation:
The URL uses the same typosquatted domain as the sender.

The path "/o365/verify" is designed to make the destination
appear related to Microsoft 365 authentication.

Assessment:
Likely credential-phishing URL.

============================================================
ANALYST NOTE
============================================================

The phishing verdict is based on multiple independent indicators,
not on a single header.

The strongest indicators are the Microsoft look-alike domain,
SPF failure, absent DKIM, DMARC failure, Reply-To mismatch,
24-hour account-suspension threat, and credential verification URL.

No suspicious link should be opened from a production workstation.
Further URL analysis should be performed only in an authorized,
isolated analysis environment.
